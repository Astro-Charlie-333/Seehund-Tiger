# Berlin — Stadt aus Licht, Schatten & Beton

Eine kleine mehrseitige Website über Berlins Geschichte, mit Fokus auf Film,
Fotografie, Kultur, Politik/DDR, Persönlichkeiten und queere/lesbische Geschichte.

## Dateien

- `index.html` — Startseite (Postkarten-Wand, von hier geht's zu allen Themen)
- `film.html`, `fotografie.html`, `kultur.html`, `politik.html`,
  `persoenlichkeiten.html`, `queer.html` — die sechs Themenseiten
- `style.css` — gemeinsames Design für alle Seiten

## Auf GitHub veröffentlichen

1. Neues Repository anlegen (öffentlich).
2. Alle Dateien hochladen — **wichtig:** `index.html` muss direkt im
   Hauptverzeichnis liegen, nicht in einem Unterordner.
3. Im Repo: **Settings → Pages → Source: „Deploy from a branch" → Branch: main → / (root) → Save**.
4. 2–3 Minuten warten. Oben erscheint dann die Live-URL
   (`https://DEINNAME.github.io/REPO-NAME/`).

## Echte Fotos einbauen (optional)

Die Seite nutzt gezeichnete Illustrationen, damit nichts kaputtgeht und keine
Urheberrechte verletzt werden. Wer echte historische Fotos möchte, findet
gemeinfreie Bilder bei **Wikimedia Commons** (auf die Lizenz achten:
„Public domain" oder „CC"). Bild herunterladen, in den Ordner legen und mit
`<img src="dateiname.jpg" alt="Beschreibung">` an der gewünschten Stelle einfügen.
